# Local artwork

Private demo builds include `spritesheet-extended.png` here. This generated
reference atlas is intentionally ignored by git; no source cat photos belong in
the repository. For a private demo build, supply an authorized transparent PNG:
8 columns × 11 rows, with legacy frame counts documented in README.md.

The source compiles without artwork and reports a clear missing-art message.
For the final gift, supply independently approved art for the three actual cats.
